# 测试用例清单：用户账户 - 登录页

## 优先级 P0 (核心功能，必须通过)
- **TC-LOGIN-001**: 成功登录
    - **前置条件**: 存在一个已激活的有效用户 (user: test@abc.com, pwd: 123456)
    - **步骤**:
        1. 访问登录页
        2. 输入 `test@abc.com`
        3. 输入 `123456`
        4. 点击“登录”按钮
    - **预期结果**:
        - 页面跳转到首页/用户中心
        - 页面左上角显示用户头像或用户名
        - URL 变为 `/home`

- **TC-LOGIN-002**: 密码错误登录
    - **前置条件**: 用户存在，且未被锁定
    - **步骤**:
        1. 访问登录页
        2. 输入正确的邮箱 `test@abc.com`
        3. 输入错误的密码 `wrongpass`
        4. 点击“登录”按钮
    - **预期结果**:
        - 显示错误提示：“用户名或密码错误”
        - 未跳转页面（仍停留在登录页）
        - 密码输入框被清空

## 优先级 P1 (重要功能/边界场景)
- **TC-LOGIN-003**: 连续5次密码错误导致账户锁定
    - **前置条件**: 用户存在，锁定阈值 = 5次
    - **步骤**:
        1. 连续输入5次错误密码
        2. 第6次尝试进行正确密码登录
    - **预期结果**:
        - 前5次：每次均提示“用户名或密码错误”
        - 第6次：提示“账户已被锁定，请15分钟后再试” 或 提示“需要找回密码”
        - 登录按钮不可用

- **TC-LOGIN-004**: 输入框为空点击登录
    - **前置条件**: 无
    - **步骤**:
        1. 在输入框为空的情况下，点击“登录”按钮
    - **预期结果**:
        - 输入框下方出现提示：“请输入邮箱” 和 “请输入密码”
        - 页面未跳转

## 优先级 P2 (边缘情况/UI/辅助功能)
- **TC-LOGIN-005**: 密码显示/隐藏切换
    - **前置条件**: 登录页加载完成
    - **步骤**:
        1. 在密码输入框输入 “MyPass1”
        2. 点击密码框右侧的“眼睛”图标
    - **预期结果**:
        - 密码文字由 `******` 变为明文 `MyPass1`
        - “眼睛”图标变为关闭状态

- **TC-LOGIN-006**: 键盘回车键登录
    - **前置条件**: 已输入有效凭据
    - **步骤**:
        1. 输入邮箱和密码
        2. 键盘按下 Enter 键
    - **预期结果**: 等同于点击登录按钮，成功登录系统。

- **TC-LOGIN-007**: 弱网环境登录
    - **前置条件**: 网络限速 (如 3G 模拟)
    - **步骤**:
        1. 输入有效凭据
        2. 点击登录
    - **预期结果**:
        - 登录按钮显示“加载中...”或转圈动画
        - 登录成功后恢复正常显示
