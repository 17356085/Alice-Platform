## P0 核心用例

### TC-001
| 字段 | 内容 |
|------|------|
| **标题** | 查看待审批列表正常加载 |
| **前置条件** | 用户已登录，存在待审批任务 |
| **步骤** | 1. 进入待审批页面<br>2. 等待列表加载完成 |
| **预期结果** | 1. 列表正确展示待审批任务<br>2. 每条记录显示：标题、申请人、申请时间、审批类型、紧急程度 |
| **优先级** | P0 |

---

### TC-002
| 字段 | 内容 |
|------|------|
| **标题** | 审批通过操作成功 |
| **前置条件** | 用户已登录，存在待审批任务 |
| **步骤** | 1. 点击任务列表中的某条待审批<br>2. 点击"通过"按钮<br>3. 填写审批意见（可选）<br>4. 确认提交 |
| **预期结果** | 1. 审批操作成功，显示成功提示<br>2. 该任务从待审批列表移除<br>3. 任务状态变更为"已通过" |
| **优先级** | P0 |

---

### TC-003
| 字段 | 内容 |
|------|------|
| **标题** | 审批拒绝操作成功 |
| **前置条件** | 用户已登录，存在待审批任务 |
| **步骤** | 1. 点击任务列表中的某条待审批<br>2. 点击"拒绝"按钮<br>3. 填写拒绝原因（必填）<br>4. 确认提交 |
| **预期结果** | 1. 审批拒绝成功，显示成功提示<br>2. 该任务从待审批列表移除<br>3. 任务状态变更为"已拒绝" |
| **优先级** | P0 |

---

### TC-004
| 字段 | 内容 |
|------|------|
| **标题** | 查看审批详情完整展示 |
| **前置条件** | 用户已登录，存在待审批任务 |
| **步骤** | 1. 点击某条待审批任务<br>2. 查看详情页面 |
| **预期结果** | 1. 详情页显示完整审批信息<br>2. 包含：申请信息、审批流程、附件、历史审批记录 |
| **优先级** | P0 |

## P1 重要用例

### TC-005
| 字段 | 内容 |
|------|------|
| **标题** | 按关键字搜索待审批任务 |
| **前置条件** | 用户已登录，存在多条待审批任务 |
| **步骤** | 1. 在搜索框输入关键字<br>2. 点击搜索按钮或按回车 |
| **预期结果** | 1. 列表仅显示匹配关键字的任务<br>2. 无匹配时显示空状态提示 |
| **优先级** | P1 |

---

### TC-006
| 字段 | 内容 |
|------|------|
| **标题** | 按审批类型筛选待审批任务 |
| **前置条件** | 用户已登录，存在不同类型的待审批任务 |
| **步骤** | 1. 点击筛选条件中的"审批类型"<br>2. 选择特定类型（如：请假、报销） |
| **预期结果** | 1. 列表仅显示选中类型的任务<br>2. 筛选条件正确显示已选中状态 |
| **优先级** | P1 |

---

### TC-007
| 字段 | 内容 |
|------|------|
| **标题** | 批量审批通过 |
| **前置条件** | 用户已登录，存在多条待审批任务 |
| **步骤** | 1. 勾选多条待审批任务<br>2. 点击"批量通过"按钮<br>3. 确认批量操作 |
| **预期结果** | 1. 选中的任务全部审批通过<br>2. 任务从待审批列表移除<br>3. 显示批量操作成功提示 |
| **优先级** | P1 |

---

### TC-008
| 字段 | 内容 |
|------|------|
| **标题** | 筛选条件重置 |
| **前置条件** | 用户已设置多个筛选条件 |
| **步骤** | 1. 设置多个筛选条件<br>2. 点击"重置"按钮 |
| **预期结果** | 1. 所有筛选条件恢复默认<br>2. 列表显示全部待审批任务 |
| **优先级** | P1 |

## P2 一般用例

### TC-009
| 字段 | 内容 |
|------|------|
| **标题** | 待审批列表分页功能 |
| **前置条件** | 待审批任务数量超过单页显示数量 |
| **步骤** | 1. 查看列表分页信息<br>2. 点击下一页<br>3. 切换每页显示数量 |
| **预期结果** | 1. 分页信息正确显示总数<br>2. 翻页正常加载对应数据<br>3. 每页数量切换后列表正确刷新 |
| **优先级** | P2 |

---

### TC-010
| 字段 | 内容 |
|------|------|
| **标题** | 审批拒绝时拒绝原因必填校验 |
| **前置条件** | 用户已登录，选择一条待审批任务 |
| **步骤** | 1. 点击"拒绝"按钮<br>2. 不填写拒绝原因<br>3. 点击确认 |
| **预期结果** | 1. 提示"请填写拒绝原因"<br>2. 审批操作未提交 |
| **优先级** | P2 |

---

### TC-011
| 字段 | 内容 |
|------|------|
| **标题** | 待审批列表为空状态展示 |
| **前置条件** | 用户已登录，无待审批任务 |
| **步骤** | 1. 进入待审批页面 |
| **预期结果** | 1. 显示空状态图标和提示文字<br>2. 提示"暂无待审批任务" |
| **优先级** | P2 |
