# Production Module - Test Cases

## P0 - Core Business Scenarios

### TC-001: 创建生产工单
- **前置条件:** 用户已登录且具有“生产计划员”角色；产品主数据、BOM、工艺路线已配置。
- **步骤:**
    1.  导航至“生产工单列表” -> 点击“新建工单”。
    2.  选择产品（如：WIP-001）。
    3.  输入计划数量（如：100）。
    4.  选择计划开始/结束日期。
    5.  点击“保存”。
- **预期结果:**
    1.  系统提示“创建成功”。
    2.  工单列表中出现新工单，状态为“已创建”，工单编号自动生成。

### TC-002: 工单状态流转 (下达->生产->完成)
- **前置条件:** 存在一个状态为“已创建”的工单（单号为WO-001）。
- **步骤:**
    1.  在工单列表页，选中WO-001 -> 点击“下达”。 (状态变为“已下达”)
    2.  进入报工页面，为WO-001报工10件 -> 提交。 (状态变为“生产中”)
    3.  继续报工，直至累计报工数量=100件 -> 提交。
    4.  回到工单列表，点击“完成”按钮。
- **预期结果:**
    1.  每次状态变更后，列表中的状态图标和文本正确更新。
    2.  工单“已完成”后，无法再进行报工操作。
    3.  下游“成品入库单”或“库存台账”中，WIP-001的库存数量增加了100。

### TC-003: 生产报工 - 核心流程
- **前置条件:** 工单WO-002，计划100件，已下达。
- **步骤:**
    1.  工人使用扫描枪扫描工单条形码/二维码。
    2.  系统自动带出工单信息。
    3.  输入报工数量：20，合格数量：19，不良品数量：1。
    4.  输入工时：2小时。
    5.  点击“提交”。
- **预期结果:**
    1.  系统提示“报工成功”。
    2.  该工单的“已完成数量”变为20，“不良品数量”变为1。
    3.  (可选) 不良品库存增加1。

## P1 - Important Scenarios

### TC-004: 工单多条件筛选
- **前置条件:** 系统中存在多个状态的工单。
- **步骤:**
    1.  筛选条件：状态 = “生产中”，产品 = “WIP-001”。
    2.  点击“查询”。
- **预期结果:**
    1.  列表仅显示状态为“生产中”且产品为“WIP-001”的工单。
    2.  分页信息正确显示筛选后的总数。

### TC-005: 报工校验 - 数量超限
- **前置条件:** 工单WO-003，计划100件，已累计报工95件。
- **步骤:**
    1.  进入WO-003的报工页。
    2.  输入报工数量：10件 (95+10 > 100)。
    3.  点击“提交”。
- **预期结果:**
    1.  系统提示错误：“报工数量不能超过计划余量（剩余5件）”。
    2.  报工失败，数据库未更新。

### TC-006: 批量下达工单
- **前置条件:** 存在3个状态为“已创建”的工单（WO-004, WO-005, WO-006）。
- **步骤:**
    1.  在工单列表页，勾选WO-004, WO-005, WO-006。
    2.  点击“批量操作” -> “批量下达”。
- **预期结果:**
    1.  系统提示“批量下达成功(3/3)”。
    2.  WO-004, WO-005, WO-006状态均变为“已下达”。

## P2 - Convenience & Usability

### TC-007: 导出工单列表
- **前置条件:** 当前筛选出若干工单。
- **步骤:**
    1.  点击“导出”按钮。
- **预期结果:**
    1.  浏览器下载一个CSV/Excel文件。
    2.  文件内容与界面列表显示的数据一致。

### TC-008: 报工记录分页查看
- **前置条件:** 某个工单有超过20条的报工记录。
- **步骤:**
    1.  进入该工单详情页 -> 查看“报工记录”Tab。
    2.  点击“下一页”。
- **预期结果:**
    1.  正确显示第2页的报工记录。
    2.  页面顶部显示“第21-40条，共N条”。
