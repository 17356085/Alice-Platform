# 系统管理模块 - 页面测试设计

## 1. 概述

本文档旨在对“系统管理”模块下的核心页面进行测试分析，设计测试策略、数据及验证点，以确保该模块的界面、功能、数据展示及交互逻辑的正确性与稳定性。

## 2. 页面结构分析

系统管理模块通常由一个配置型导航页和若干功能子页面组成。基于通用设计，分析如下典型页面结构：

### 2.1 用户管理页面

*   **核心区域**:
    *   **查询/过滤区**: 搜索框 (用户名/邮箱/手机号), 状态下拉框 (启用/禁用/全部), 角色下拉框, 创建时间选择器。
    *   **功能区**: “新增用户”按钮(主操作), “导出用户”按钮(次要操作)。
    *   **数据展示区**: 分页表格 (展示用户列表: 用户名, 真实姓名, 手机号, 邮箱, 角色, 所属部门, 状态, 最后登录时间, 操作列)。
    *   **对话/弹出层**: 新增/编辑用户的表单, 重置密码表单, 分配角色对话窗, 确认删除/禁用/启用对话框。

### 2.2 角色管理页面

*   **核心区域**:
    *   **功能区**: “新增角色”按钮。
    *   **数据展示区**: 卡片或列表形式展示角色 (角色名称, 角色描述, 用户数量, 创建时间, 更新时间, 操作列)。
    *   **对话/弹出层**: 新增/编辑角色表单 (角色名称, 角色编码, 描述, 状态), 权限分配树形控件弹窗。

### 2.3 操作日志页面

*   **核心区域**:
    *   **查询/过滤区**: 操作类型下拉框, 操作者搜索框, 时间范围选择器 (预置: 今天, 最近7天, 最近30天, 自定义), 模块筛选。
    *   **数据展示区**: 分页列表/表格 (时间, 操作者, 操作IP, 操作类型(增/删/改/查), 操作模块, 操作描述, 操作结果(成功/失败))。
    *   **辅助功能**: 日志详情查看弹窗, 日志导出按钮。

### 2.4 系统配置页面

*   **核心区域**:
    *   **功能区**: “保存”按钮(全局)。
    *   **表单区**: 通常为分组表单 (如: 基础设置), 包含文本输入框, 单选框, 开关, 数字输入框等控件 (例如: 系统名称, Logo, 默认语言, 会话超时时间, 密码策略等)。

## 4. 测试策略与数据设计

### 4.1 测试策略
1.  **正向流程测试**: 验证每个页面的CRUD主流程按预期执行 (新增->查询->编辑->禁用/启用->删除)。
2.  **UI / 数据一致性**: 验证页面元素 (列表, 详情, 搜索条件) 的数据来源一致，显示格式正确。
3.  **权限隔离测试**: 验证不同权限角色的用户 (超级管理员, 普通管理员, 审计员) 看到的菜单、按钮、数据范围一致。
4.  **边界与异常值测试**:
    *   **空数据场景**: 列表无数据时的引导或提示文字。
    *   **搜索无结果**: 返回空列表的提示。
    *   **超长文本**: 用户名/配置值超长时的截断、tooltip 提示。
    *   **并发操作**: 两个管理员同时修改同一配置/角色。
5.  **交互与体验测试**:
    *   **加载状态**: 点击操作后应有加载反馈 (loading 动画/按钮禁用)。
    *   **无感刷新**: CRUD操作后列表自动刷新，不跳页或保持当前页。
    *   **重复提交**: 快速重复点击提交按钮防止产生重复数据。

## 5. 关键验证点 (Checklist)

*   [ ] **数据加载**: 所有列表/下拉框数据加载正确，无404/500错误。
*   [ ] **查询过滤**: 所有查询条件组合后，结果与预期一致。
*   [ ] **新增功能**: 必填项校验，数据格式校验，重复数据提示，成功创建后列表刷新。
*   [ ] **编辑功能**: 回填默认值，修改后更新，唯一字段不可修改或修改后校验。
*   [ ] **删除功能**: 二次确认弹窗，确认后删除，删除后列表刷新。
*   [ ] **状态变更**: 启用/禁用操作成功，状态更新成功即时。
*   [ ] **分页功能**: 总条数，当前页码，跳页，每页显示条数切换 (10/20/50) 均工作正常。
*   [ ] **日志记录**: 关键操作 (增/删/改/导出) 均记录在操作日志中，信息完整无误。
*   [ ] **权限控制**: 无权限用户看不到入口/按钮，或点击后提示“无权限”。
*   [ ] **数据回滚**: 角色删除后，已关联该角色的用户状态或关联关系按业务逻辑处理。
*   [ ] **并发控制 (乐观锁)**: 系统配置/角色编辑时，如果有其他人在你之前保存，应提示“数据已被修改，请刷新后重试”。
*   [ ] **性能**: 列表加载（特别是操作日志大表）、搜索响应时间在可接受范围内。
