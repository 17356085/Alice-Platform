## 测试用例列表

### 1. 用户列表加载与展示 - P0

*   **ID:** SM-LIST-001
*   **标题:** 用户列表默认加载
*   **前置条件:** 1. 存在至少3个不同角色的用户。2. 管理员用户已登录。
*   **测试步骤:**
    1.  导航至“系统管理”模块。
    2.  观察页面加载过程中的加载指示器。
    3.  等待页面加载完成。
    4.  检查用户列表的呈现。
*   **预期结果:**
    1.  页面加载时显示加载动画或骨架屏（Skeleton）。
    2.  加载完成后，列表正常显示所有用户。
    3.  每行用户数据包含：ID、用户名、角色、邮箱、状态、创建时间、操作列（编辑、删除）。
    4.  列表支持分页，默认显示10条/页。
    5.  当前页，页码信息和总记录数正确。
*   **优先级:** P0

### 2. 新增用户 - 正向用例 - P0

*   **ID:** SM-CREATE-001
*   **标题:** 成功创建一个有效用户
*   **前置条件:** 1. 管理员用户已登录。2. 用户“test_new”在系统中不存在。3. 新增用户表单所有字段均为必填。
*   **测试步骤:**
    1.  点击“新增用户”按钮。
    2.  在弹出的新增表单中，输入有效的用户名: `test_new`。
    3.  选择一个非管理员角色（如：普通用户）。
    4.  输入有效邮箱: `new@example.com`。
    5.  输入密码: `Complex@123`。
    6.  输入确认密码: `Complex@123`。
    7.  点击“保存”或“提交”按钮。
*   **预期结果:**
    1.  表单验证通过，无错误提示。
    2.  页面显示“用户创建成功”的提示（toast或弹窗）。
    3.  弹窗自动关闭。
    4.  用户列表自动刷新，并在第一页或最后一页显示新创建的用户“test_new”。
    5.  该用户的状态为“启用”。
*   **优先级:** P0

### 3. 新增用户 - 反向用例 - P1

*   **ID:** SM-CREATE-002
*   **标题:** 创建用户 - 重复用户名
*   **前置条件:** 1. 管理员用户已登录。2. 用户“admin”已存在于系统中。
*   **测试步骤:**
    1.  点击“新增用户”按钮。
    2.  在新增表单中，输入已存在的用户名: `admin`。
    3.  填写其他必填字段（角色、邮箱、密码等）。
    4.  点击“保存”按钮。
*   **预期结果:**
    1.  点击保存后，表单不会提交。
    2.  用户名输入框下方或顶部显示明确的错误提示，如“用户名已存在”或“该账号已被注册”。
    3.  用户列表不发生任何变化。
*   **优先级:** P1

### 4. 编辑用户 - 正向用例 - P0

*   **ID:** SM-UPDATE-001
*   **标题:** 成功修改用户角色
*   **前置条件:** 1. 管理员用户已登录。2. 用户列表已加载。3. 选择一个非管理员的目标用户（例如：用户A，当前角色：普通用户）。
*   **测试步骤:**
    1.  在用户列表中，找到用户A。
    2.  点击该用户行右侧的“编辑”按钮。
    3.  在弹出的编辑表单中，将用户A的角色从“普通用户”修改为“管理员”。
    4.  点击“保存”按钮。
*   **预期结果:**
    1.  页面显示“用户更新成功”的提示。
    2.  编辑弹窗关闭。
    3.  用户列表中，用户A的角色字段更新为“管理员”。
*   **优先级:** P0

### 5. 编辑用户 - 反向用例 - P1

*   **ID:** SM-UPDATE-002
*   **标题:** 编辑用户 - 修改邮箱为无效格式
*   **前置条件:** 1. 管理员用户已登录。2. 选择一个有效的目标用户。
*   **测试步骤:**
    1.  点击该用户的“编辑”按钮。
    2.  在邮箱输入框中，输入无效的格式，如 `test`（无@符号）。
    3.  点击“保存”按钮。
*   **预期结果:**
    1.  点击保存后，表单不会提交。
    2.  邮箱输入框下方显示错误提示，如“请输入有效的邮箱地址”。
    3.  用户信息未被更新。
*   **优先级:** P1

### 6. 删除用户 - 正向用例 - P0

*   **ID:** SM-DELETE-001
*   **标题:** 成功删除一个用户
*   **前置条件:** 1. 管理员用户已登录。2. 用户列表中存在一个没有任何关联资源（如：未创建工单）的测试用户“test_delete”。
*   **测试步骤:**
    1.  在用户列表中，找到测试用户“test_delete”。
    2.  点击该用户行右侧的“删除”按钮。
    3.  系统弹出二次确认对话框，内容应包含用户名信息。
    4.  点击确认对话框中的“确定”或“确认删除”按钮。
*   **预期结果:**
    1.  页面显示“用户删除成功”的提示。
    2.  用户列表自动刷新，测试用户“test_delete”不再显示。
*   **优先级:** P0

### 7. 删除用户 - 反向用例 - P1

*   **前置条件:** 1. 管理员用户已登录。2. 选择一个有效的目标用户。

*   **预期结果:**
    1.  弹窗关闭，页面不发生任何变化。
    2.  用户列表完整无变化。
*   **优先级:** P1

### 8. 用户搜索/筛选功能 - P1

*   **ID:** SM-SEARCH-001
*   **标题:** 按用户名搜索用户
*   **前置条件:** 1. 管理员用户已登录。2. 用户列表包含 `test_user_01` 和 `admin`。
*   **测试步骤:**
    1.  在搜索输入框中，输入关键词 `test`。
    2.  点击搜索按钮或按回车键。

### 9. 权限控制检查 - P0

*   **ID:** SM-PERM-001
*   **标题:** 非管理员用户访问系统管理页面
*   **前置条件:** 1. 一个角色为“普通用户”的账号已登录。
*   **测试步骤:**
    1.  获取页面上“系统管理”的菜单入口（可能已被隐藏）。
    2.  如果可见，点击进入；如果不可见，尝试直接通过URL访问该页面。
*   **预期结果:**
    1.  页面上不应存在“系统管理”的入口或菜单项。
    2.  如果通过URL直接访问，应返回“无权限”或“404”页面，或者被重定向到首页，并提示权限不足。
    3.  无法对用户数据进行任何增删改查操作。
*   **优先级:** P0
