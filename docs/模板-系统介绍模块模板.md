# 鞍集(凌源)管理系统操作手册

---

## 1 系统概述

### 1.1 系统简介

鞍集(凌源)管理系统是面向工业企业的一体化生产运营管理平台。系统整合了人员管理、设备管理、储罐管理、化验室取样、生产管理、库管管理、销售管理等核心业务模块，旨在提高企业生产运营效率和管理水平。

### 1.2 主要功能

本系统提供以下核心功能：

**基础管理**
- 系统管理：用户权限配置、组织架构维护、系统监控
- 人员管理：员工信息维护、培训考试、承包商管理

**生产运营**
- 设备管理：设备台账、维保记录、传感器管理
- 储罐管理：储罐监控、日报表管理
- 化验室取样：水质/气体分析、指标管理、报告生成
- 生产管理：日报/月报、班次配置、业务类型管理

**供应链**
- 库管管理：备品备件、三剂消耗、环保危废管理
- 销售管理：客户、合同、订单、销售报表

### 1.3 系统访问

**Web端访问地址**
```
https://aiwechatminidemo.cimc-digital.com/
```

**支持的浏览器**
- Google Chrome（推荐，版本90+）
- Mozilla Firefox（版本88+）
- Microsoft Edge（版本90+）

**推荐分辨率**
- 最佳分辨率：1920x1080
- 最低分辨率：1366x768

## 2 登录与退出

### 2.1 登录系统

**操作步骤**

1. 打开浏览器，输入系统地址：`https://aiwechatminidemo.cimc-digital.com/`
2. 在登录页面输入用户名和密码
3. 点击【登录】按钮
4. 登录成功后，系统跳转至首页工作台

![登录页面](images/01-系统介绍/01-登录页面.png)

**注意事项**
- 首次登录建议修改初始密码
- 连续输错密码5次，账号将被锁定15分钟
- 如忘记密码，请联系系统管理员重置

### 2.2 退出系统

**操作步骤**

1. 点击页面右上角的用户头像或用户名
2. 在下拉菜单中选择【退出登录】
3. 系统返回登录页面

![退出登录](images/01-系统介绍/02-退出登录.png)

## 3 界面布局说明

系统界面采用经典的三栏布局结构，主要包括：顶部导航栏、左侧菜单栏、右侧工作区。

![系统主界面](images/01-系统介绍/03-系统主界面.png)

### 3.1 顶部导航栏

顶部导航栏包含以下元素：

| 区域 | 功能说明 |
|------|---------|
| 系统Logo和名称 | 显示系统名称"鞍集(凌源)管理系统" |
| 搜索按钮 | 全局搜索功能 |
| 全屏按钮 | 切换全屏显示模式 |
| 通知铃铛 | 查看系统通知和消息 |
| 用户信息 | 显示当前登录用户名，点击可展开用户菜单 |

### 3.2 左侧菜单栏

左侧菜单栏是系统的功能导航区域，采用树形结构组织。

**菜单特点**
- **可折叠**：点击菜单栏顶部的折叠按钮，可收起/展开菜单栏
- **多级菜单**：支持一级菜单、二级菜单、三级菜单
- **图标标识**：每个一级菜单都有对应的图标
- **高亮当前**：当前所在页面的菜单会高亮显示

**菜单层级示例**
```
一级菜单：系统管理
  ├── 二级菜单：用户管理
  ├── 二级菜单：角色管理
  └── 二级菜单：日志管理
        └── 三级菜单：登录日志
        └── 三级菜单：操作日志
```

**操作说明**
1. 点击一级菜单，展开/收起二级菜单
2. 点击二级菜单，展开/收起三级菜单（如有）
3. 点击最终菜单项，右侧工作区加载对应页面

### 3.3 标签页栏

标签页栏显示当前打开的页面，支持多标签页操作。

| 操作 | 说明 |
|------|------|
| 新增标签 | 点击左侧菜单打开新页面时，自动新增标签 |
| 切换标签 | 点击标签可快速切换到对应页面 |
| 关闭标签 | 点击标签右侧的【×】关闭当前标签 |
| 关闭其他 | 右键标签，选择"关闭其他"关闭除当前外的所有标签 |
| 关闭所有 | 右键标签，选择"关闭所有"关闭所有标签 |

**注意**：首页标签不可关闭。

### 3.4 右侧工作区

右侧工作区是系统的主要操作区域，根据左侧菜单选择加载对应的功能页面。

工作区通常包含以下区域：
- **搜索筛选区**：位于页面顶部，用于输入查询条件
- **操作按钮区**：位于搜索区下方，包含【新增】、【导出】等操作按钮
- **数据列表区**：位于页面主体，以表格形式展示数据
- **分页区**：位于页面底部，用于翻页操作

## 4 通用操作说明

本节介绍系统中各模块通用的操作方法。

### 4.1 查询/搜索

几乎每个列表页面都提供查询功能。

**操作步骤**

1. 在搜索区输入查询条件（如名称、编码、状态等）
2. 点击【查询】或【搜索】按钮
3. 系统显示符合筛选条件的数据列表
4. 如需清空条件重新查询，点击【重置】按钮

![查询操作](images/01-系统介绍/04-查询操作.png)

**查询技巧**
- 支持模糊查询：输入部分内容即可匹配
- 支持组合查询：可同时输入多个条件进行筛选
- 支持下拉选择：部分字段提供下拉选项

### 4.2 新增数据

**操作步骤**

1. 在列表页面点击【新增】按钮
2. 系统弹出新增弹窗/跳转到新增页面
3. 填写表单信息（带*号的为必填项）
4. 点击【确定】或【保存】按钮
5. 系统提示"新增成功"，列表自动刷新

![新增操作](images/01-系统介绍/05-新增弹窗.png)

**注意事项**
- 必填项未填写会显示红色提示
- 填写格式错误会有相应提示
- 新增成功后会自动关闭弹窗

### 4.3 编辑数据

**操作步骤**

1. 在列表中找到需要编辑的数据行
2. 点击该行的【编辑】按钮
3. 在弹窗中修改需要变更的信息
4. 点击【确定】保存修改
5. 系统提示"修改成功"，列表自动刷新

**注意事项**
- 编辑时会回显原有数据
- 部分字段可能不允许修改（如编码）
- 修改后需保存才会生效

### 4.4 删除数据

**操作步骤**

1. 在列表中找到需要删除的数据行
2. 点击该行的【删除】按钮
3. 系统弹出确认框："确定删除吗？"
4. 点击【确定】执行删除
5. 系统提示"删除成功"，列表自动刷新

**注意事项**
- 删除操作不可恢复，请谨慎操作
- 关联数据可能无法删除（系统会提示）
- 部分数据支持批量删除

### 4.5 导出数据

**操作步骤**

1. 在列表页面点击【导出】按钮
2. 系统开始生成导出文件
3. 浏览器自动下载Excel文件

**注意事项**
- 导出的是当前查询条件下的数据
- 数据量大时导出可能需要等待
- 导出文件为Excel格式（.xlsx）

### 4.6 分页操作

当数据量较大时，系统会自动分页显示。

| 操作 | 说明 |
|------|------|
| 翻页 | 点击页码或【上一页】【下一页】按钮 |
| 切换每页条数 | 在分页区选择"10条/页"、"20条/页"、"50条/页" |
| 跳转页面 | 输入页码，点击【前往】或按回车跳转 |
| 查看总数 | 在分页区显示"共XX条" |

![分页操作](images/01-系统介绍/06-分页操作.png)

## 5 数据权限说明

系统采用基于角色的数据权限控制，不同角色可查看的数据范围不同。

### 5.1 数据权限层级

| 数据范围 | 含义 | 典型角色 |
|---------|------|---------|
| 全部数据 | 可查看系统所有部门的数据 | 超级管理员、管理员 |
| 本组织及下级数据 | 可查看本部门及下属部门的数据 | 部门管理员、主管 |
| 本组织数据 | 仅可查看本部门的数据 | 普通员工(小程序端) |
| 仅本人数据 | 仅可查看自己创建/相关的数据 | 普通员工(Web端) |

### 5.2 权限生效规则

- 数据权限在查询时自动生效
- 用户只能看到权限范围内的数据
- 新增数据时，数据归属自动关联到当前用户所属组织
- 无权限访问的菜单不会显示在左侧菜单栏

## 6 工作流审批通用说明

系统支持工作流审批功能，用于处理需要多级审批的业务流程。

### 6.1 审批入口

用户可通过以下方式进入审批页面：

**方式一：通过菜单**
```
系统管理 > 工作流管理 > 待我审批
```

**方式二：通过首页待办**
在首页工作台的"我的待办"区域，可直接点击待审批事项。

### 6.2 审批操作

**审批步骤**

1. 进入【待我审批】页面
2. 查看待审批列表
3. 点击【审批】按钮查看审批详情
4. 选择审批结果（通过/驳回）
5. 填写审批意见（可选）
6. 点击【确定】完成审批

**审批状态说明**

| 状态 | 含义 |
|------|------|
| 待审批 | 等待当前审批人处理 |
| 审批中 | 流程正在进行，等待后续节点 |
| 已通过 | 审批流程已完成，申请通过 |
| 已驳回 | 审批被驳回，需申请人重新处理 |
| 已撤回 | 申请人主动撤回了申请 |

### 6.3 查看审批记录

**操作步骤**

1. 进入【我已审批】页面，查看已处理的审批记录
2. 进入【我发起的】页面，查看自己提交的申请
3. 点击任一记录可查看审批详情和审批链

## 7 小程序端访问说明

部分功能支持通过小程序访问，适用于移动端办公场景。

### 7.1 小程序登录

1. 打开微信，搜索并进入鞍集(凌源)管理系统小程序
2. 使用与Web端相同的账号密码登录
3. 首次登录需进行身份验证

### 7.2 小程序端功能

小程序端主要支持以下功能：
- 待办事项处理
- 审批操作
- 基础数据查询
- 现场拍照上报

### 7.3 小程序端角色

小程序端使用独立的角色体系，包括：
- 管理员(小程序)
- 领导层(小程序)
- 部门主管(小程序)
- 承包商(小程序)
- 普通员工(小程序)
- 仓库领用员

## 常见问题

| 序号 | 问题描述 | 解决方案 |
|------|---------|---------|
| 1 | 忘记登录密码 | 联系系统管理员重置密码 |
| 2 | 页面加载缓慢 | 检查网络连接，或尝试刷新页面（F5） |
| 3 | 菜单找不到某个功能 | 确认当前账号是否有该功能的访问权限 |
| 4 | 数据列表为空 | 检查查询条件是否过于严格，点击【重置】清空条件 |
| 5 | 导出文件乱码 | 使用Excel打开导出文件，选择UTF-8编码 |
| 6 | 弹窗无法关闭 | 刷新页面后重试，或联系技术支持 |
