## 二、编写顺序

按照从基础到业务的顺序编写：

1. **01-系统介绍** - 登录、退出、界面布局、通用操作
2. **02-系统管理** - 用户、角色、菜单、组织、日志、工作流（基础配置）
3. **03-设备管理** - 设备台账、装置、摄像头、传感器、维保
4. **04-储罐管理** - 储罐监控、日报表
5. **05-化验室取样** - 水质/气体分析
6. **06-人员管理** - 员工、岗位、培训（含员工自助功能）
7. **07-生产管理** - 日报、月报、班次配置
8. **08-库管管理** - 备品备件、三剂消耗、环保危废
9. **09-销售管理** - 客户、合同、订单

## 三、截图规范

### 截图存放路径
`docs/images/模块编号-模块名称/`

示例：
```
docs/images/02-系统管理/01-用户管理界面.png
docs/images/02-系统管理/02-新增用户弹窗.png
docs/images/06-人员管理/01-课程管理列表.png
```

### 截图命名规则
- 格式：`序号-功能描述.png`
- 示例：`01-用户管理界面.png`、`02-新增用户弹窗.png`、`03-角色权限配置.png`

### 截图要求
- **关键操作截图**：新增/编辑弹窗、提交成功提示、重要配置界面
- **非关键操作不截图**：查询、翻页等简单操作
- **截图清晰度**：100%缩放，分辨率不低于1280x720
- **截图标注**：使用中文描述，如"图1 用户管理主界面"

## 四、工作流说明规则

### 统一说明位置
所有工作流相关操作统一在 **"02-系统管理模块操作手册"** 中说明，包括：
- 待我审批
- 我已审批
- 我发起的
- 审批链配置

### 各业务模块说明方式
各业务模块中**仅说明该模块涉及的审批流程**，格式如下：

```markdown
#### X.X.X 功能名称

[功能说明]

##### 审批流程
1. 操作人提交申请
2. 主管审批通过

4. 系统自动更新库存

**审批入口：**`系统管理`>`工作流管理`>`待我审批`
```

## 六、文档格式要求

### 通用格式
- 使用Markdown格式编写
- 标题层级清晰（H1-H4）
- 表格使用标准Markdown表格语法
- 截图使用相对路径：`![图片描述](images/模块名/图片文件名.png)`

### 字段说明格式
```markdown
| 字段名称 | 是否必填 | 字段说明 |
|---------|---------|---------|
| 字段1 | 是 | 说明... |
| 字段2 | 否 | 说明... |
```

### 异常情况格式
```markdown
| 异常描述 | 异常原因 | 解决方案 |
|---------|---------|---------|
| 提示"xxx" | 原因... | 解决方法... |
```

### 操作步骤格式
```markdown
**操作名称**

1. 点击【按钮名称】
2. 在弹窗中填写表单信息
3. 点击【确定】保存
4. 系统提示"操作成功"
```
