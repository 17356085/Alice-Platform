### 1. 页面上下文分析 (PAGE_CONTEXT.md 映射)

**模块定义:** 销售管理

**核心功能:**
- **列表/筛选:** 查看销售订单/商机列表，按状态、时间、客户、销售员等条件筛选。
- **新建/编辑:** 创建新的销售订单或商机，或修改现有记录。
- **详情查看:** 点击列表项查看完整信息。
- **状态流转:** （可选）审核、发货、关闭等生命周期管理。
- **数据导出:** 将列表数据导出为 Excel/CSV。

**典型用户角色:**
- **销售员:** 创建自己的订单/商机，查看自己负责的列表。
- **销售主管:** 查看团队列表，审核订单，进行数据分析。
- **管理员:** 查看全量数据，配置销售流程。

**关键用户路径:**
1.  登录 -> 进入销售模块 -> 按状态筛选 -> 查看列表 -> 点击“创建” -> 填写表单 -> 保存 -> 返回列表验证新条目。
2.  登录 -> 查看列表 -> 点击某项 -> 进入详情页 -> 点击“编辑” -> 修改关键字段 -> 保存 -> 返回详情验证更新。
3.  登录 -> 查看列表 -> 勾选多项 -> 点击“批量导出”。

#### 4.2 数据测试覆盖

- **正常数据：** 标准的客户名、有效日期、正数金额。
- **边界数据：**
    - 字符串长度（0 字符、最大允许长度、超长 1 字符）。
    - 数字范围（0.01、最大可接受金额、接近最大值的数字）。
    - 日期范围（今天、下个月第一天、去年、2099年）。
- **异常/干扰数据：**
    - 特殊字符（`<script>`、`&`、SQL注入关键字）。
    - 空值（在非必填字段留空，在必填字段留空）。
    - 重复数据（创建相同订单号的订单，验证是否有重复校验）。

#### 4.3 非功能性测试关注点

- **性能：** 切换到100条/页时，页面是否卡顿？快速点击翻页按钮是否触发多次请求？
- **兼容性：** 在不同浏览器（Chrome, Firefox, Edge）上，模态框的关闭按钮、日期选择器是否位置正确？
- **用户体验：** 加载数据时是否有 Loading 动画？筛选条件变化后是自动查询还是需要手动点击查询按钮？
