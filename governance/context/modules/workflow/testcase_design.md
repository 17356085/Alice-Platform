## P0 — 核心流程

### TC-001：待审批列表正常加载
| 字段 | 内容 |
|------|------|
| **前置条件** | 用户已登录，拥有待审批数据，网络正常 |
| **步骤** | 1. 进入 workflow 模块<br>2. 导航至「待审批」页面 |
| **预期结果** | 页面正常渲染，列表展示当前用户的待审批事项，包含标题、发起人、提交时间、流程类型、当前状态等字段 |
| **优先级** | P0 |

---

### TC-002：审批通过（正向）
| 字段 | 内容 |
|------|------|
| **前置条件** | 列表中存在至少 1 条待审批记录 |
| **步骤** | 1. 点击某条待审批记录的「审批」按钮<br>2. 在审批弹窗/页面中填写审批意见（必填项填写完整）<br>3. 点击「通过」按钮 |
| **预期结果** | 1. 操作成功提示（如"审批通过"）<br>2. 该条记录从待审批列表中移除<br>3. 流程流转至下一节点 |
| **优先级** | P0 |

---

### TC-003：审批拒绝（反向流程）
| 字段 | 内容 |
|------|------|
| **前置条件** | 列表中存在至少 1 条待审批记录 |
| **步骤** | 1. 点击某条待审批记录的「审批」按钮<br>2. 在审批弹窗/页面中填写拒绝意见<br>3. 点击「拒绝」按钮 |
| **预期结果** | 1. 操作成功提示<br>2. 该条记录从待审批列表中移除<br>3. 流程回退或终止，发起人收到驳回通知 |
| **优先级** | P0 |

---

### TC-004：不填审批意见提交（反向）
| 字段 | 内容 |
|------|------|
| **前置条件** | 审批意见为必填项 |
| **步骤** | 1. 点击「审批」按钮<br>2. 不填写审批意见<br>3. 点击「通过」或「拒绝」 |
| **预期结果** | 提交失败，表单校验提示「请输入审批意见」，不发送请求 |
| **优先级** | P0 |

---

### TC-005：查看待审批详情
| 字段 | 内容 |
|------|------|
| **前置条件** | 列表中存在待审批记录 |
| **步骤** | 1. 点击某条记录的标题或「查看」按钮 |
| **预期结果** | 进入详情页/展开详情面板，展示审批表单内容、附件、流程历史、发起人信息等完整数据 |
| **优先级** | P0 |

---

## P1 — 重要功能

### TC-006：按流程类型筛选
| 字段 | 内容 |
|------|------|
| **前置条件** | 存在多种流程类型的待审批数据（如请假、报销、合同） |
| **步骤** | 1. 在筛选区域选择流程类型<br>2. 点击「查询」 |
| **预期结果** | 列表仅展示所选流程类型的记录 |
| **优先级** | P1 |

---

### TC-007：按关键词搜索
| 字段 | 内容 |
|------|------|
| **前置条件** | 列表中存在可搜索的数据 |
| **步骤** | 1. 在搜索框输入关键词<br>2. 点击搜索或回车 |
| **预期结果** | 列表返回匹配标题/发起人等字段的记录 |
| **优先级** | P1 |

---

### TC-008：搜索无结果
| 字段 | 内容 |
|------|------|
| **前置条件** | — |
| **步骤** | 1. 在搜索框输入不存在的关键词<br>2. 回车搜索 |
| **预期结果** | 列表为空，展示「暂无数据」空状态提示 |
| **优先级** | P1 |

---

### TC-009：分页功能
| 字段 | 内容 |
|------|------|
| **前置条件** | 待审批记录数 > 每页条数 |
| **步骤** | 1. 查看默认分页<br>2. 点击下一页<br>3. 跳转至指定页码 |
| **预期结果** | 1. 每页显示正确的条数<br>2. 翻页后数据正确切换<br>3. 总条数与实际一致 |
| **优先级** | P1 |

---

### TC-010：批量审批
| 字段 | 内容 |
|------|------|
| **前置条件** | 页面支持批量操作，存在多条待审批记录 |
| **步骤** | 1. 勾选多条记录（含全选）<br>2. 点击「批量通过」 |
| **预期结果** | 1. 选中记录全部审批通过<br>2. 列表刷新，已审批记录移除<br>3. 提示批量操作成功及数量 |
| **优先级** | P1 |

## P2 — 辅助场景

### TC-011：无权限用户访问页面
| 字段 | 内容 |
|------|------|
| **前置条件** | 使用无 workflow 审批权限的账号登录 |
| **步骤** | 1. 尝试直接访问待审批页面 URL |
| **预期结果** | 显示 403 无权限提示或跳转至首页 |
| **优先级** | P2 |

---

### TC-012：网络异常时审批操作
| 字段 | 内容 |
|------|------|
| **前置条件** | 打开审批弹窗 |
| **步骤** | 1. 断开网络<br>2. 点击「通过」按钮 |
| **预期结果** | 请求失败，展示网络异常提示，审批弹窗不关闭，数据未变更 |
| **优先级** | P2 |

---

### TC-013：审批意见超长输入
| 字段 | 内容 |
|------|------|
| **前置条件** | 审批意见有字数上限（如 500 字） |
| **步骤** | 1. 输入超过上限的字符<br>2. 观察输入行为 |
| **预期结果** | 输入被截断至最大长度，或实时提示「最多输入 X 字」，不允许超限提交 |
| **优先级** | P2 |
