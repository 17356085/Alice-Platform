## 详细测试用例

### TC-001：查看我的申请列表

| 项目 | 内容 |
|------|------|
| **前置条件** | 用户已登录，且至少有1条申请记录 |
| **步骤** | 1. 进入工作流模块<br>2. 点击"我的申请"菜单 |
| **预期结果** | 1. 页面正确加载，显示申请列表<br>2. 列表包含：申请编号、申请类型、申请时间、当前状态、操作按钮<br>3. 默认按时间倒序排列 |
| **优先级** | P0 |

**反向用例 TC-001b：无申请记录时的展示**

| 项目 | 内容 |
|------|------|
| **前置条件** | 用户已登录，无任何申请记录 |
| **步骤** | 1. 进入工作流模块<br>2. 点击"我的申请"菜单 |
| **预期结果** | 显示空状态提示，如"暂无申请记录" |
| **优先级** | P1 |

### TC-002：新建工作流申请

| 项目 | 内容 |
|------|------|
| **前置条件** | 用户已登录，具有申请权限 |
| **步骤** | 1. 进入"我的申请"页面<br>2. 点击"新建申请"按钮<br>3. 选择申请类型（如请假申请）<br>4. 填写必填字段（起止时间、事由等）<br>5. 点击"提交" |
| **预期结果** | 1. 跳转到申请表单页面<br>2. 提交成功后返回列表<br>3. 列表顶部显示新提交的申请<br>4. 状态显示为"待审批" |
| **优先级** | P0 |

**反向用例 TC-002b：必填字段未填写时提交**

| 项目 | 内容 |
|------|------|
| **前置条件** | 用户已登录，进入新建申请表单 |
| **步骤** | 1. 不填写必填字段<br>2. 直接点击"提交" |
| **预期结果** | 1. 表单验证失败<br>2. 必填字段下方显示红色错误提示<br>3. 无法提交成功 |
| **优先级** | P0 |

| **优先级** | P1 |

| **步骤** | 1. 在搜索框输入不存在的关键词<br>2. 点击搜索按钮 |
| **预期结果** | 显示空状态提示"未找到匹配的申请记录" |
| **优先级** | P1 |

### TC-004：撤回待审批的申请

| 项目 | 内容 |
|------|------|
| **前置条件** | 用户已登录，存在状态为"待审批"的申请 |
| **步骤** | 1. 进入"我的申请"页面<br>2. 找到待审批的申请记录<br>3. 点击"撤回"操作按钮<br>4. 在确认弹窗中点击"确认" |
| **预期结果** | 1. 弹出二次确认弹窗<br>2. 确认后申请状态变更为"已撤回"<br>3. 该申请不再流转到审批人 |
| **优先级** | P0 |

**反向用例 TC-004b：已审批的申请无法撤回**

| 项目 | 内容 |
|------|------|
| **前置条件** | 用户已登录，存在已审批通过/拒绝的申请 |
| **步骤** | 1. 查看已审批的申请记录<br>2. 检查是否有"撤回"按钮 |
| **预期结果** | "撤回"按钮不显示或置灰不可点击 |
| **优先级** | P1 |

### TC-008：分页功能验证

| 项目 | 内容 |
|------|------|
| **前置条件** | 用户已登录，申请记录超过每页显示数量（如10条） |
| **步骤** | 1. 进入"我的申请"页面<br>2. 点击下一页<br>3. 点击上一页<br>4. 跳转到指定页码 |
| **预期结果** | 1. 分页组件正确显示（总条数、总页数、当前页）<br>2. 翻页后列表数据正确更新<br>3. 当前页码高亮显示 |
| **优先级** | P2 |

**反向用例 TC-008b：输入无效页码**

| 项目 | 内容 |
|------|------|
| **前置条件** | 用户已登录，申请记录共5页 |
| **步骤** | 1. 在页码输入框输入0或负数<br>2. 输入超过总页数的数字（如999） |
| **预期结果** | 自动修正为有效页码或提示错误 |
| **优先级** | P2 |
