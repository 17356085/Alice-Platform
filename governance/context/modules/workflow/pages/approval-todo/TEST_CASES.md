### 详细测试用例

**ID: AT-P0-01**
*   **标题:** 单条审批记录：同意操作
*   **前置条件:**
    1.  用户已登录，且有待办事项权限。
    2.  页面至少存在一条状态为“待我审批”的记录。
*   **步骤:**
    1.  导航至 `approval-todo` 页面。
    2.  在表格中定位到第一条状态为“待我审批”的记录。
    3.  点击该记录操作列的“同意”按钮。
    4.  在可能的确认弹窗中，点击“确认”。
*   **预期结果:**
    1.  出现`Loading`状态（`.ant-spin-spinning`可见）。
    2.  `Loading`状态消失。
    3.  页面出现成功提示（`.ant-message-success`可见）。
    4.  该记录的状态更新为“已同意”或从“待我审批”列表中消失。
    5.  总待办数量（`.ant-pagination-total-text`）相应减少1条。
*   **优先级:** P0

**ID: AT-P0-02**
*   **标题:** 批量审批记录：批量同意操作
*   **前置条件:**
    1.  用户已登录，且有待办事项批量操作权限。
    2.  页面至少存在两条状态为“待我审批”的记录。
*   **步骤:**
    1.  导航至 `approval-todo` 页面。
    2.  勾选表格中前两条记录的复选框。
    3.  点击“批量同意”按钮 `[data-testid=“btn-batch-approve“]`。
    4.  在确认弹窗中，点击“确认”。
*   **预期结果:**
    1.  “批量同意”按钮在勾选前为禁用状态，勾选后变为启用状态。
    2.  出现`Loading`状态。
    3.  `Loading`状态消失。
    4.  页面出现成功提示。
    5.  被选中的两条记录状态更新为“已同意”或从“待我审批”列表中消失。
    6.  表头全选复选框 `[data-testid=“checkbox-selectAll“]` 状态更新（从选中/半选变为未选中）。
    7.  总待办数量相应减少2条。
*   **优先级:** P0

**ID: AT-P1-01**
*   **标题:** 按流程类型筛选待办列表
*   **前置条件:**
    1.  用户已登录。
    2.  页面存在不同“流程类型”的待办记录（如“请假申请”，“报销审批”）。
*   **步骤:**
    1.  导航至 `approval-todo` 页面。
    2.  在“流程类型”下拉框 `[data-testid=“filter-processType“]` 中，选择“请假申请”。
    3.  点击“查询”按钮。
    4.  观察表格数据变化。
*   **预期结果:**
    1.  下拉框的值更新为“请假申请”。
    2.  页面出现`Loading`状态，随后消失。
    3.  表格中所有记录的“流程类型”列内容均为“请假申请”。
    4.  分页器总条数（`.ant-pagination-total-text`）更新，且等于“请假申请”类型待办的总数。
*   **优先级:** P1

**ID: AT-P1-02**
*   **标题:** 分页功能：翻页查看数据
*   **前置条件:**
    1.  用户已登录。
    2.  待办列表总数据量大于单页显示条数（例如，共15条，每页显示10条）。
*   **步骤:**
    1.  导航至 `approval-todo` 页面，确认处于第一页。
    2.  记录当前第一页表格中第一条记录的标题或ID。
    3.  点击分页器的“下一页”按钮 `.ant-pagination-next`。
    4.  等待数据加载完成。
*   **预期结果:**
    1.  初始状态，第一页为激活状态，“上一页”按钮 `.ant-pagination-prev` 为禁用。
    2.  “下一页”按钮为启用状态。
    3.  点击后出现`Loading`状态。
    4.  `Loading`消失后，表格显示第二页的数据。
    5.  第二页表格第一条记录与步骤2记录的**内容不同**。
    6.  分页器指示“第2页”。
    7.  “上一页”按钮变为启用状态。
*   **优先级:** P1

**ID: AT-P2-01**
*   **标题:** 页面空状态展示
*   **前置条件:**
    1.  用户已登录。
    2.  模拟或配置当前用户没有任何待办事项（或使用特定筛选条件使结果为空）。
*   **步骤:**
    1.  导航至 `approval-todo` 页面，或设置筛选条件使查询结果为空。
*   **预期结果:**
    1.  表格区域不显示任何数据行。
    2.  显示空状态插图/组件（`.ant-empty` 或 `[data-testid=“empty-state“]` 可见）。
    3.  分页器总条数显示为“共 0 条”或类似无数据提示。
*   **优先级:** P2

**ID: AT-P2-02**
*   **标题:** 筛选器重置功能
*   **前置条件:**
    1.  用户已登录。
*   **步骤:**
    1.  导航至 `approval-todo` 页面。
    2.  在“流程类型”下拉框中选择一个非默认选项。
    3.  在“关键词”输入框 `[data-testid=“filter-keyword“]` 中输入“测试”。
    4.  点击“重置”按钮。
*   **预期结果:**
    1.  所有筛选器控件恢复默认状态。
    2.  “流程类型”下拉框恢复为默认选项（如“全部”）。
    3.  “关键词”输入框被清空，值为空字符串。
    4.  （可选）页面自动执行一次查询，展示重置后的全量数据。
*   **优先级:** P2
