## 二、用例清单

### TC-001 【P0】页面正常加载与列表数据展示

| 项目 | 内容 |
|------|------|
| **用例ID** | TC-001 |
| **标题** | SAP同步日志页面正常加载并展示日志列表 |
| **优先级** | P0 |
| **前置条件** | 1. 已登录系统<br>2. 已有至少1条SAP推送日志数据 |
| **操作步骤** | 1. 导航至 workflow → SAP同步日志<br>2. 等待页面加载完成 |
| **预期结果** | 1. 页面标题显示「SAP同步日志」<br>2. 表格列依次显示：推送时间、同步类型、单据类型、单据编号、SAP单号、公司名称、公司代码、摘要、同步状态、操作<br>3. 推送时间格式为 `YYYY-MM-DD HH:mm:ss`<br>4. 同步状态以标签形式展示（成功/失败/等待中），颜色区分<br>5. 操作列显示「查看详情」链接 |
| **关联风险** | F-001, D-001 |
